# Operational Rules & Constraints

## STRICT RESTRICTION: NO GIT ACCESS
- Under NO circumstances is the AI assistant permitted to run any `git` commands (e.g., `git status`, `git diff`, `git log`, `git checkout`, `git add`, `git commit`, etc.).
- Do not inspect, read, or modify anything inside the `.git` directory.
- The user has explicitly forbidden any access to or operations on Git.
